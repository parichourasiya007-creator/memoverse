Create a complete, high-fidelity, professional web application prototype called **MEMOVERSE**.

**Tagline:**
**Where Memories Come Alive**

MemoVerse is an AI-assisted cognitive activity and memory-support platform designed for elderly users and their families/caregivers, with a special focus on accessibility, regional languages, local culture, and offline-first usability in the North Eastern Region of India.

## MOST IMPORTANT USER FLOW

**DO NOT ask for Login, Sign Up, Profile, OTP, Email, Password, or any account information when the website opens.**

The user must be able to:

**Open Website → Home Page → Learn About Dementia → Explore Activities → Play Games**

without creating an account.

The platform should feel welcoming and useful before asking the user for any personal information.

Only when the user wants personalized features should authentication/profile creation appear.

### Account/Profile should appear only when:

1. User clicks **Start Your Journey**
2. User clicks **Profile**
3. User tries to use **Reminders**
4. User wants to save **personal memories/progress**

The main cognitive games should remain playable without login.

# 2. AWARENESS SECTION — ABOUT DEMENTIA

This is an important part of the homepage.

Create a simple awareness section explaining dementia in easy language.

Heading:

**Understanding Dementia**

Text:

**Dementia is a condition that can affect memory, thinking, communication, and everyday activities. It is more than normal ageing and can affect people differently.**

Create four simple information cards:

### 🧠 Memory Changes

A person may have difficulty remembering recent events, conversations, or familiar information.

### 🗣️ Communication

Finding the right words or following conversations can sometimes become difficult.

### 🏡 Everyday Activities

Familiar daily tasks may become more challenging over time.

### ❤️ Support Matters

Patience, familiar environments, meaningful activities, and family support can help a person feel more comfortable and connected.

Add an important note:

**MemoVerse does not diagnose or treat dementia. It provides cognitive activities, memory support, and awareness resources.**

# 16. GRANDPARENT MODE

The entire UI should follow a **Grandparent Mode** philosophy.

Requirements:

* Large readable fonts
* High contrast
* Large buttons
* Clear icons + text
* Minimal navigation
* Simple instructions
* Maximum 3 major actions on important screens
* Audio guidance
* Optional haptic feedback
* No tiny text
* No confusing menus
* No unnecessary pop-ups
* No pressure-based timers
* Calm transitions

The experience should feel:

**Calm + Respectful + Familiar + Trustworthy**

Not childish.

---

# 17. VISUAL DESIGN

Default:

**Light Mode**

Background:

White / very light neutral

Text:

Deep navy / near black

Primary buttons:

Deep navy

Cards:

White with subtle gray borders

Use green only for success states and offline/online status.

Use red only for important warnings.

Dark mode:

Deep navy/charcoal background
White text
High-contrast controls
Slightly lighter dark cards

Avoid:

* Warm yellow highlights
* Pastel-heavy colors
* Neon
* Excessive gradients
* Flashy animations
* Cartoon-style graphics
* Childish game interfaces
* Hospital dashboard aesthetics
* Excessive medical imagery

Use subtle rounded corners and soft shadows.
